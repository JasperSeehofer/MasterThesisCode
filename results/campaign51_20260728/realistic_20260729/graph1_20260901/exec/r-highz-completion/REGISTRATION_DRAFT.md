## 2. Definitions

**2.1 Term profiles (per event e, per node h; full-precision columns only, MECHANISM_NOTE §4):**
`T_B,e(h) = ln B_num`, `T_g,e(h) = ln B_num_wbh − ln B_num`, `T_D(h) = −den_log_term` (event-common).
Identity for e ∈ P_dark: `ln combined_with_bh = T_B + T_g + T_D`, `ln combined_no_bh = T_B + T_D` (gate G-1).
Centred profiles `t̂_e(h) = t_e(h) − t_e(0.73)`; an additive per-event constant is immaterial to `mean_h`
(the joint posterior is normalised over h; `exp(const)` cancels) — so profiles are compared as SHAPES.
**2.2 Reference profile:** `t̄(h) = median_{e∈R} t̂_e(h)` per node (a low-z zero-candidate "typical shape"),
computed once per venue/channel/term. Robust to the heavy tails of row #344; the mean is reported alongside.
**2.3 Term-freeze counterfactual (the primary object):** with `Λ_full(h) = Σ_e ln L_e(h)` (T0 convention,
physics floor as in `_load_matrix`), for a term t and the target set K_dark:
`Λ_t(h) = Λ_full(h) − Σ_{e∈K_dark} t̂_e(h) + |K_dark|·t̄(h)`; **Δ_t = mean_h(Λ_t) − mean_h(Λ_full)**.
The all-terms freeze `Λ_F` replaces `t̂_e` by `t̄` for EVERY separable term (2D: B and g; 1D: B); `Δ_F` is the
freeze TOTAL. `Δ_D` (freezing T_D) is `0` by identity — evaluated and reported as an identity gate (G-1c), not a
measurement. **Closure:** `r = Δ_F − Σ_t Δ_t` (non-additivity of `mean_h`), disclosed as `|r|/|Δ_F|`.
**Share:** `s_t = Δ_t / Δ_F`. Also reported: the plain leave-out `Δ_K,dark = mean_h(Λ_full − Σ_{K_dark} ln L_e) − mean_h(Λ_full)`
and `Δ_F / Δ_K,dark`, `Δ_K,dark / Δ_K` (with `Δ_K = +0.086106` the anchor) — concordance ratios, reported-only.
**2.4 Per-term score excess (venue-transferable, first order):** three-node stencil at h ∈ {0.725, 0.730, 0.735}
(inside the 0.005-spaced core; no seam), `t'_e = [t_e(0.735) − t_e(0.725)] / 0.010`;
`S_t = mean_{e∈K_dark} t'_e − mean_{e∈R} t'_e` (nats per unit h, per event), `S_F = Σ_t S_t` (T_D cancels exactly).
SE by the two-sample Welch formula over events (production) / by the between-universe jackknife of the pooled
value (harness). **Transfer ratio** `ρ_S = S_F^harn / S_F^prod` (with `S_t^harn / S_t^prod` per term), the row-#347
convention; **stencil consistency** `Δ_t ≈ |K_dark|·S_t / I_HEAD` reported-only (not a gate).
**2.5 Null draws (production g-precision):** 1000 draws of `|K_dark|` events from `P_dark \ K` (seed 20260904,
`numpy.random.default_rng`), each given the same all-terms freeze against the same `t̄`; the CI99 of `Δ_F` under
no z-structure. The registered `Δ_F` is adjudicated only if outside that CI99 (else Z-DIFFERENTIAL-NULL, §5).
