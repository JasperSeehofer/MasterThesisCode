## 2. Method

`darksiren_emri/validation/venue_transfer.py::run_v_t5_compat_check` was read but **not
modified**. It computes, in v2-compat mode, the same instrument path used here:

- universe via `calibration_gate.draw_universe_gate`
- ball via `calibration_gate.draw_ball` (N = 1500, λ = 4, σ_z = 0.035, canonical grid)
- posteriors via `venue_transfer.log_channel_posteriors_ball_sigma_vector` (this module's
  vector-σ core, constant σ_z vector, `chunk_pairs=0` exact gate-shape mode)
- per-seed record assembled by `venue_transfer._gate_style_record`

against the committed `results/calibration_gate_v2_20260810/B2_h0p730_results.json` on the
registered v2 seeds **20286808, 20286809, 20286810**. `run_v_t5_compat_check` itself scores this
with an exact `!=` comparison — the **old** bit-identity rule, not the registered V-M5 condition,
and was intentionally left untouched (rails).

`verify_vm5_golden.py` reruns the identical computation (same functions, same seeds, same
committed reference) and scores it against the **registered** condition instead:

- for every field shared between the recomputed record and the committed record (44 scalar and
  vector fields, including the two 41-point `ln_post_1d`/`ln_post_2d` vectors flattened per index),
  compute the relative deviation `|mine - ref| / max(|ref|, 1e-300)`, or exact equality for
  non-numeric fields;
- report the max relative deviation per field, per seed, and overall;
- separately assert `map_1d`, `map_2d`, `map_1d_refined`, `map_2d_refined` are **exactly** equal
  (not just within rtol) in every seed — the "both channels' MAP values are exactly equal" clause;
- V-M5 passes iff every field is within rtol ≤ 1e-12 **and** all four MAP fields are exact in every
  seed.
