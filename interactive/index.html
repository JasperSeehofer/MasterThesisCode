EMRI Dark Siren H₀ — Interactive Figures

Jasper Seehofer — Master Thesis, Heidelberg University

This page provides browser-explorable versions of key figures from the EMRI dark siren H₀ inference pipeline. Each figure is fully interactive: hover over data points for exact values, toggle legend entries to isolate traces, and zoom or pan to explore regions of interest.

  • Combined H₀ Posterior Joint posterior over the dimensionless Hubble parameter h from all detected EMRI events, with a flat-prior overlay, nested 50/68/95% HDI shading, both mass-channel variants (one blue hue, solid vs dashed), Planck-pink / SH0ES-cyan reference bands, and an optional HOPs Play button that cycles bootstrap posterior draws.
  • Sky Localization Map Mollweide projection of detected EMRI event sky positions, colour-coded by signal-to-noise ratio. Hover for per-event SNR, redshift, and luminosity distance.
  • Fisher Matrix Error Ellipses Cramer–Rao parameter uncertainty ellipses for selected pairs of EMRI parameters. 1σ and 2σ contours shown per event; zoom in to compare event-to-event spread.
  • H₀ Posterior Convergence Two-panel diagnostic: combined posterior sharpening as more events are included (left) and credible-interval width vs event count with a 1/√N reference (right).
  • H₀ Tension Explorer The combined H₀ posterior shown against the Planck (pink) and SH0ES (cyan) tension bands, with a native slider that scrubs the number of stacked events. Press Play to watch the measurement sharpen as detections accumulate.
  • Mz Improvement Explorer Three-panel interactive answer to "did adding the redshifted MBH mass channel Mz tighten the H₀ posterior?" — bootstrap-banded metric curves (HDI width, relative precision, fractional improvement, effective event gain) vs. number of detections, with a per-N posterior overlay and a live improvement summary strip.
  • Single-Event Detail Explorer For one EMRI detection at a time, six interactive panels show all candidate host galaxies with and without the BH-mass cut: per-galaxy weights, side-by-side comparison, and the resulting per-event L(h) curves. Use the dropdown to switch between representative events.
  • Closure Test Overlay Combined H₀ posteriors from independent runs with htrue ∈ {0.60, 0.65, 0.70, 0.73, 0.75} overlaid on a single axis — each posterior should peak near its own injection truth. Demonstrates pipeline closure across injection cosmologies.
  • Catalog Coverage & Host Counts GLADE+ catalog coverage vs luminosity distance plus per-event candidate-host counts. Visualises how the BH-mass cut reduces the host pool (median reduction ≈ 64 % across the 1473-event campaign).
Figures generated from EMRI simulation data. Toggle legend entries, hover for values, zoom and pan to explore.
Data version: 2026-05-15 refresh on phase46-merged Cramér–Rao bounds. Posterior figures use the unified canonical raw Σ log Li combination (Phase A; matches the test_28 verdict JSON cited throughout docs/H0_BIAS_RESOLUTION.md). 63-point non-uniform h-grid (Δh=0.001 dense core in [0.710, 0.750] + Δh=0.010 wings spanning [0.600, 0.860]) evaluated on 1 473 SNR ≥ 20 events at htrue = 0.73; discrete MAP = 0.7380, continuous MAP = 0.7378 for both 1D and 2D channels (Phase-48 May 7 verdict: MAP 0.732 at z = +1.16 σ / +0.97 σ).
