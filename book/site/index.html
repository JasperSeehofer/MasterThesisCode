From Bayes’ Rule to H₀ an interactive discovery book

From Bayes’ rule to the EMRI dark-siren H₀ pipeline

A step-by-step, interactive companion to the thesis. Every representation is introduced with its motivation — either “without this, the posterior is defective” (shown, not asserted) or “this addition measurably helps, here is how much.” The book ends where the research currently ends: with the estimator's live, honestly inconsistent state.

Status This book is under active construction against the build spec in book/design/BOOK_DESIGN.md. The chapter-0 pipeline demo is a fully working, fully offline proof of the publishing chain (real data in, an interactive figure out); it will be retired once the real chapters below land.

How this book is built

No build framework — plain HTML/CSS/JS, vendored Plotly and KaTeX, works over a trivial local server and on GitHub Pages alike. See book/design/BOOK_TECH_DESIGN.md for the architecture and book/design/BOOK_DESIGN.md for the authoritative chapter build spec.
