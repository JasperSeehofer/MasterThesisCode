<objective>
Modernize every 2D map in the plotting package: perceptually-uniform cividis default,
an explicit norm + `set_bad` no-data color on every heatmap, true-axis `pcolormesh` for the
pdet surface, a norm fix for the sky-map SNR scatter, a reusable diverging convention
(built-in cmap, no new dependency) for future bias/residual maps, and semantic contour
overlays where they aid reading.

Purpose: Dynamic range is currently washed out (viridis + autoscale) and NaN/no-data bins
render invisible. After this phase, sequential maps read with full dynamic range, no-data
bins read as no-data, the pdet surface has physically-faithful (log) mass spacing and
correct distance units, and the diverging convention is established for the first bias map.

Output: Recolored/renormed plotting factories (signatures + (fig,ax) contract unchanged),
three new `_helpers` utilities (`diverging_norm`, `make_heatmap_norm`, `credible_contour_levels`),
two new `_colors` constants (`DIVERGING_CMAP`, `NO_DATA`), `CMAP="cividis"`, the mplstyle
default flipped to cividis, and tests asserting the new conventions.

ROUTING NOTE — this is GSD, NOT physics. Every change is colormap / norm / axis-presentation
only. No formula, constant, PSD coefficient, waveform parameter, or frequency limit is
touched. NEVER invoke `/physics-change`. No data-plumbing/loader change.
</objective>
