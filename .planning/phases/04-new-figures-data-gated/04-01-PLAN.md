`binomial_confidence_bands(n_injections: int, confidence_levels: tuple[float, ...] = (0.68, 0.95, 0.997), n_grid: int = 101) -> dict[float, tuple[NDArray[np.float64], NDArray[np.float64]]]`:
  - bilby recipe: `x = np.linspace(0, 1, n_grid)`; for each CL, `edge = (1 - cl) / 2`; `lower = binom.ppf(edge, n_injections, x) / n_injections`; `upper = binom.ppf(1 - edge, n_injections, x) / n_injections`. Return `{cl: (lower, upper)}`. (1/2/3-sigma == 0.68/0.95/0.997.)
